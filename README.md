# Sistema de Detecção de Obstáculos SENSÍVEL AO CONTEXTO  para Pessoas com Deficiência Visual

## Descrição
Sistema UBÍQUO VESTÍVEL baseado em Inteligência Artificial para identificar obstáculos em tempo real.

## Problema
Pessoas com deficiência visual enfrentam dificuldades na locomoção segura em ambientes urbanos.

## Solução
Modelo capaz de identificar obstáculos e auxiliar na tomada de decisão.

## Tecnologias
- C /Arduíno
- Aprendizado de Máquinas - KNN
- Processamento de dados
- Computação sensível ao Contexto
- Computação Ubíqua
- Computação vestível
- Computação embarcada

## Aplicações
- Acessibilidade
- Sistemas embarcados
- Cidades inteligentes

Projeto desenvolvido durante a pesquisa de Mestrado
